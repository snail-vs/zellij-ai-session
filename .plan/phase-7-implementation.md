# 阶段 7：长列表导航

实施日期：2026-09-24。

## 完成范围

- 树视图增加 `C` / `E`：折叠或展开全部项目。批量操作仅修改项目折叠状态，会话自身的展开状态保持不变。
- 折叠全部项目时，如果选中会话因此隐藏，光标移到其所属项目；选中项目时仍停留在该项目。
- 树视图增加 `g` / `G` / `M`，跳到当前可见树的首项、末项和中位项。偶数项时取靠前项。
- 批量折叠、展开和跳转均根据最近一次树视图渲染的列表高度修正滚动位置；空树会安全保留零选中项和零滚动位置。
- 底部快捷键说明列出新增操作。
- 空格键切换选中项目或有子会话的会话的展开状态；会话叶节点不执行操作。Enter 仍用于打开会话。

## 验证

- 静态检查实现路径：导航索引从 `tree_items()` 计算，因而只包含当前展开状态下的可见项；绘制前的 `ensure_visible()` 以当前终端尺寸再次校正选中项和滚动窗口。
- 本阶段未运行测试或构建命令。
- 真实 Alt-S 交互仍需人工验收：长列表下验证 `C` / `E`、`g` / `G` / `M`，并检查窄屏滚动与折叠会话树后的选中项。

## 后续调整

- 增加空格键作为选中可展开项的折叠 / 展开切换键，Enter 继续打开会话；已同步插件快捷键提示和主需求文档。

## 限制和后续

- 终端高度变化由下一次渲染重新计算可视窗口；快捷键事件使用最近一次渲染时记录的高度。
- 未改变预览协议或会话数据模型。后续无需依赖新的索引器接口。
